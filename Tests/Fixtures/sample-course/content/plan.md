# Course plan

Choose a goal. Read the course. Check your work.

![Course sections](../media/section.svg)

## Steps

1. Write the **goal** of the course.
2. Put the lectures in order.
3. Check each lecture with the `skillgarden` CLI.

## Notes

- Keep each lecture short.
- Read the [Skillgarden guide](https://example.com/guide) for more help.

```
skillgarden publish ./course
```
